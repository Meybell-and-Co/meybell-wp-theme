# Meybell Framework

A modular, WordPress-first framework for building maintainable, accessible, and thoughtfully documented websites.

## Documentation

- [Architecture](docs/ARCHITECTURE.md)
- [Git Workflow](docs/GIT.md)

## Philosophy

The Meybell Framework emphasizes:

- WordPress-first development
- Clear separation of responsibilities
- Documentation as a product
- Design systems before pages
- Editor experience as part of the product

See the documentation for implementation details.

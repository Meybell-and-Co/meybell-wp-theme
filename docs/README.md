# Meybell Framework Documentation

This directory contains practical guidance for working within the Meybell Framework repository.

These documents explain how contributors should use, maintain, and extend the framework.

## Documentation Map

- [Git Workflow](GIT.md)

## Scope

Repository documentation should remain specific to the Meybell Framework.

General educational material, research, broader development knowledge, and working notes belong in the Meybell & Co. Google Drive knowledge system.

## Guiding Principle

Documentation should live as close as practical to the thing it describes.
